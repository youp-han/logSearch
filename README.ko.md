## 한글

### 로그 필터 (Log Filter)

지정된 로그 파일(.txt, .log)에서 특정 키워드가 포함된 라인만 추출하여 새로운 파일로 저장하는 Windows Forms 애플리케이션입니다.

### 주요 기능
- **파일 선택**: '파일 찾기' 버튼 또는 드래그 앤 드롭으로 로그 파일을 지정할 수 있습니다.
- **키워드 검색**: 원하는 검색어를 입력하여 로그를 필터링합니다. (기본값: "error")
- **결과 표시**: 필터링된 결과를 화면의 리스트 박스에 표시합니다.
- **파일 저장**: 결과를 별도의 텍스트 파일로 저장합니다. (형식: `원본파일이름-yyyyMMdd-filttered.txt`)
- **결과 열기**: 저장된 결과 파일을 버튼 클릭으로 바로 열어 확인할 수 있습니다.

### 사용법
1. `파일 찾기` 버튼을 클릭하거나 파일을 창으로 드래그하여 로그 파일을 선택합니다.
2. 검색할 키워드를 입력합니다. (기본값은 "error" 입니다.)
3. `검색` 버튼을 클릭하여 필터링을 실행합니다.
4. 결과가 화면에 표시되고 지정된 경로에 파일로 저장됩니다.
5. `결과 파일 열기` 버튼으로 저장된 파일을 바로 확인할 수 있습니다.
